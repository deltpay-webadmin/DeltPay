# Delt Sales Agent Recruiting Package

Internal hiring documents for the 1099 Merchant Services Sales Agent role (Indeed).

| File | Purpose |
|---|---|
| `indeed-job-posting.md` | The posting to publish on Indeed, including screening questions |
| `comp-plan-one-pager.md` | Comp structure + earnings scenarios; send to candidates after first contact |
| `strategy-memo.md` | Internal rationale: title, split framing, quasi-benefits, compliance guardrails |
| `interview-offer-script.md` | First-call structure, objection responses, offer script |

**Keep the numbers in sync.** The banded activation bonuses ($150–$1,000 by merchant volume), the Delt Capital commission (3% of funded amount, renewals included), the Fast Start milestones ($500 for 3-in-30, $1,000 for 10-in-90, $1,500 lifetime cap), the 8-deal monthly retro kicker (+$50/deal), the tier splits (50% / 60% / 70%), the per-account residual assumption (~$45/mo at Tier 1), the Active Producer perks (closer-on-call for the first 90 days, weekly deal lab, free Delt for the agent's own business, gym ≤$15/mo, telehealth, enrollment support; 3+ activations/trailing 90 days), the 10% single-level recruiting override (+$250 at recruit's 5th activation), the Referral Partner track (15% of net program revenue for life of account), the quarterly President's Club, and the scenario tables appear in multiple files. KORONA POS is no longer part of the comp structure. If one number changes, change them all.

Items marked `[FOUNDER TO CONFIRM]` are open decisions — resolve them before publishing the posting or sending the one-pager to a candidate.
