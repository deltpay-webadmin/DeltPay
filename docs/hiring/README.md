# Delt Sales Agent Recruiting Package

Internal hiring documents for the 1099 Merchant Services Sales Agent role (Indeed).

| File | Purpose |
|---|---|
| `indeed-job-posting.md` | The posting to publish on Indeed, including screening questions |
| `comp-plan-one-pager.md` | Comp structure + earnings scenarios; send to candidates after first contact |
| `strategy-memo.md` | Internal rationale: title, split framing, quasi-benefits, compliance guardrails |
| `interview-offer-script.md` | First-call structure, objection responses, offer script |
| `agent-agreement.md` | Source text of the 1099 agent agreement (**draft — counsel must review before first signature**) |
| `Delt-Sales-Agent-Agreement.docx` | Signable Word version: Agreement + Schedule A (fee schedule / net revenue) + Schedule B (comp plan) + ACH authorization, one signature page |
| `Delt-Agent-Compensation-Plan.docx` | Polished candidate-facing comp plan; content mirrors `comp-plan-one-pager.md` |
| `agent-onboarding-sop.md` | **Internal** SOP: application → signature (incl. ACH + W-9 collection) → provisioning → payouts → offboarding |

**The agent portal's "Your Program at a Glance" is the source of truth for core comp.** That means: banded activation bonuses ($150–$1,000 by merchant volume, +$100 POS/Capital attached), tier splits 50% / 60% / 70% at day one / 15+ / 35+ active accounts, and Fast Start ($500 for 3-in-30, $1,000 for 10-in-90, $1,500 cap). The momentum kicker was cut — it must not appear anywhere. On top of that, these docs also carry: the Delt Capital commission (3% of funded amount, renewals included, stacks with the attach kicker — in the portal's comp module and glance panel), the per-account residual assumption (~$45/mo at Tier 1), the Active Producer perks (founder closer support for the first 90 days, weekly training, lead flow, free Delt for the agent's own business, gym ≤$15/mo, telehealth, enrollment support; 3+ activations/trailing 90 days), the 10% single-level recruiting override (+$250 at recruit's 5th activation), the Referral Partner track (15% of net program revenue for life of account), the quarterly President's Club, and the scenario tables. These appear in multiple files — if one number changes, change them all, and keep the portal matching.

Items marked `[FOUNDER TO CONFIRM]` are open decisions — resolve them before publishing the posting or sending the one-pager to a candidate.
